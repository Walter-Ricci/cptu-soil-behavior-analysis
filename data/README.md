# Dataset

The raw dataset is intentionally not redistributed in this repository.

Download **Cone penetration test dataset Premstaller Geotechnik** from the article repository:

- DOI: https://doi.org/10.1016/j.dib.2020.106618
- Dataset licence reported by the publisher: CC BY 4.0
- Expected input file: `mmc1.csv`

Keep the downloaded file outside Git or under `data/raw/`, which is ignored. The command-line interface accepts its location through `--input`; no Windows-specific path is embedded in the package.

If data are redistributed in the future, retain attribution, provenance and the CC BY 4.0 notice. The MIT licence in this repository covers only the original software.
